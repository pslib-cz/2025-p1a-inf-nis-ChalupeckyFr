# Gitcraft - Github pro minecraft projekty
## Perex
**Gitcraft** je specializovaná platforma pro správu a verzování Minecraft projektů, která přebírá sílu GitHubu, ale balí ji do čistého a srozumitelného rozhraní pro běžné tvůrce, stavitele i programátory. Systém funguje jako webová i desktopová aplikace, což umožňuje pracovat na projektech offline s automatickou synchronizací po připojení k síti. Hlavní inovací je integrované lokální „testovací okno“, které dokáže během pár vteřin nasimulovat změny v odlehčeném Minecraft světě bez nutnosti zdlouhavě spouštět celou hru. Gitcraft tak zásadně zjednodušuje a zrychluje spolupráci na pluginech, módech i mapách.
